# SpaceSurvival 0.3.1

Help-layout correction for the visual clarity release.

- Localized help now tightens line spacing when taller platform fonts would overflow a panel, retaining all copy and the 12 px minimum font size.
- Browser checks for Aegis and Overcharge advance controlled simulation frames so slow rendering cannot introduce a second hit or delay the expected lockout expiry.

Includes the ships, hostile-shot warnings, colony scenery, asteroid and ion-hazard graphics from 0.3.0. Combat rules and saved-run compatibility are unchanged. No dependency or external asset was added.

The public build includes `release.json` identifying its exact committed source revision.
