# Space Survival — Playable Build

Play the latest published build at **https://dpio.github.io/space-survival/**.

This public repository contains only the generated browser distribution. Source development is maintained separately.

## Controls

- Move: WASD or arrow keys
- Aim: mouse
- Fire: primary mouse button or Space
- Build panel: B
- Mute: M
- New arena: R
- Menu: Escape

No unverified third-party assets or production source maps are included.
